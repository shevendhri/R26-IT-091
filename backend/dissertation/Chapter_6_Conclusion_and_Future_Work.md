# Chapter 6: Conclusion and Future Work

## 6.1 Conclusion
This research successfully developed, implemented, and validated GreenConstructAI, an end-to-end generative design system. By automating blueprint generation, material specification, and furniture layout, the pipeline drastically reduces early-stage architectural design time. The validation dataset of 80 scenarios empirically proves that the Hybrid Scoring mechanism effectively balances deterministic engineering constraints with machine learning aesthetic evaluations. The system demonstrates robust adaptability across varying building types, budget tiers, and climate zones.

## 6.2 Future Work
1. **3D Deep Learning**: Transitioning the ML layout evaluation from 2D heuristic approximations to true 3D graph neural networks.
2. **User Studies**: Conducting empirical validation through A/B testing with professional architects to correlate the Hybrid Score with human expert preferences.
3. **Dynamic Footprints**: Upgrading the procedural generator to handle non-orthogonal and organic building boundaries.
4. **Energy Simulation**: Integrating dynamic thermal and daylight simulation tools directly into the sustainability evaluation module.
